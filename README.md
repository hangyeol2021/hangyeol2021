## Selected project

### [Focus Sense · 공시](https://github.com/hangyeol2021/focus-sense)

**자세 인식 기반 공부시간 측정 웹 서비스**

웹캠으로 학습 자세를 인식해 시간을 자동으로 측정하고, 사용자별 학습 기록을 AWS에 저장합니다.

- **AI in the browser** — Teachable Machine과 TensorFlow.js를 활용한 자세 인식
- **Web experience** — 자동·수동 타이머와 Google 로그인
- **Cloud backend** — Cognito 인증, API Gateway, Lambda, DynamoDB 연동
- **Deployment** — EC2와 Nginx, CloudFront를 활용한 웹 배포

[서비스 실행 ↗](https://dd0vak8p8f011.cloudfront.net) · [소스 코드](https://github.com/hangyeol2021/focus-sense) · [한국어 문서](https://github.com/hangyeol2021/focus-sense/blob/main/README.ko.md) · [日本語](https://github.com/hangyeol2021/focus-sense/blob/main/README.md) · [English](https://github.com/hangyeol2021/focus-sense/blob/main/README.en.md)
